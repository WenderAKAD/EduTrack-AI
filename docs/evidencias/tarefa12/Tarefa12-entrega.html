1 Objetivo e conceitos-chave

O objetivo é escrever a lógica de cálculo de progresso de uma disciplina em Python e empregá-la como custom function do Xano — o percentual de tarefas concluídas que alimentará o dashboard do app.

ConceitoO que significa no projeto
Custom functionFunção em Python hospedada no Xano, invocada por uma query. Recebe e devolve JSON.
Contrato JSONEntrada {"tasks": [...]} → saída {"percentage": ...}.
Python restritoAmbiente do Xano permite apenas built-ins; o script importa somente json.
Spec-Driven DevelopmentA regra de cálculo foi especificada antes do código, em progress-calculation/spec.md.

3 O script calculate_progress.py

Três funções públicas e o ponto de entrada handle(payload), usado pelo Xano:

def calculate_progress(completed_tasks, total_tasks):
    """Retorna {"percentage": x} de 0 a 100; 0 quando nao ha tarefas."""
    if total_tasks <= 0:
        return {"percentage": 0}
    return {"percentage": round(completed_tasks / total_tasks * 100, 2)}

def is_completed(task):
    """Uma tarefa conta como concluida quando o status e 'completed'."""
    status = str(task.get("status", "")).strip().lower()
    return status == COMPLETED_STATUS

def calculate_subject_progress(tasks):
    tasks = tasks or []
    total_tasks = len(tasks)
    completed_tasks = sum(1 for task in tasks if is_completed(task))
    return calculate_progress(completed_tasks, total_tasks)

def handle(payload):
    """Entrada/saida JSON: {"tasks": [...]} -> {"percentage": ...}."""
    if isinstance(payload, str):
        payload = json.loads(payload)
    return calculate_subject_progress(payload.get("tasks", []))
DecisãoPor quê
Só built-insO Xano executa funções em ambiente restrito; apenas json é importado.
Status canônicoUma tarefa é concluída quando status, após trim e lower, é completed.
Divisão por zerototal_tasks <= 0 devolve {"percentage": 0} em vez de levantar ZeroDivisionError.
Arredondamentoround(..., 2) — duas casas bastam para exibição e evitam ruído de ponto flutuante.
