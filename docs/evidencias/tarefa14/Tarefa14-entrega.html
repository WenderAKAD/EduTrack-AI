1 Objetivo e Abordagem Híbrida

O objetivo da Tarefa 14 é implementar uma funcionalidade de busca avançada inteligente que utilize de forma sinérgica o banco de dados no Xano e uma lógica analítica em Python.

A arquitetura adotada divide as responsabilidades com máxima eficiência:

  • Lado Xano (Banco Relacional): Efetua a busca por nome na tabela subjects utilizando o operador case-insensitive ilike, garantindo indexação rápida e filtro rigoroso de propriedade por user_id == $auth.id.
  • Lado Python (Regra Analítica): O script scripts/search_overdue_subjects.py define e valida a regra de calendário e pendência (due_date < hoje e status != 'completed'), identificando quais disciplinas estão em atraso.
  • Lado XanoScript (Execução): A custom function functions/search_overdue_subjects.xs porta a mesma regra para o backend, recebendo as tarefas e disciplinas do usuário e devolvendo apenas as disciplinas com pendência vencida.

3 Função Analítica em Python

Implementada em scripts/search_overdue_subjects.py sem dependências externas (Python standard library), facilitando execução local e validação da regra. A mesma lógica é portada para a custom function functions/search_overdue_subjects.xs, que executa a verificação no backend Xano.

def is_overdue_task(task: Dict, today: date = None) -> bool:
    """Tarefa atrasada: status != completed e due_date < hoje."""
    if today is None:
        today = date.today()
    status = str(task.get("status", "")).strip().lower()
    if status == "completed":
        return False
    due = task.get("due_date")
    if not due:
        return False
    try:
        due_date = date.fromisoformat(due[:10])
        return due_date < today
    except Exception:
        return False

4 Endpoint XanoScript

O endpoint GET /subjects/search foi adicionado ao grupo de APIs Autenticacao EduTrackIA Est em apis/autenticacao_edutrack_ia_est/subjects_search_GET.xs. Quando overdue=true, ele chama a custom function functions/search_overdue_subjects.xs com as tarefas e disciplinas do usuário autenticado.

Parâmetro Tipo Obrigatório Efeito
q text Não Filtro parcial case-insensitive por nome (name ilike %q%)
overdue text ("true") Não Filtra somente disciplinas com tarefas atrasadas e pendentes
Combinação inteligente: Se ambos os parâmetros forem informados (?q=Lab&overdue=true), o endpoint busca no banco apenas as disciplinas correspondentes a "Lab" do usuário autenticado e, em seguida, a custom function search_overdue_subjects mantém apenas aquelas que possuem pendências vencidas.

6 Segurança e Isolamento por Usuário

  • Autenticação JWT Obrigatória: auth = "user" no topo do endpoint XanoScript impede acesso anônimo.
  • Restrição no Banco: where = $db.subjects.user_id == $auth.id garante que o estudante jamais visualize disciplinas de terceiros.
  • Restrição de Tarefas: where = $db.academic_tasks.subject_id.user_id == $auth.id assegura que nenhuma tarefa alheia entre no cálculo de atraso.
