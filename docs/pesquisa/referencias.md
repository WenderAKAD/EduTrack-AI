Pesquisa de referências gratuitas no **Figma Community** e no **Xano Marketplace**
para orientar o design e a estrutura do EduTrack AI. O objetivo é fazer

listas de tarefas e bases de usuário — **sem copiar projetos inteiros**.

## Figma Community

> Todos os templates abaixo são **gratuitos** (verificados no Figma Community:
> indicam "Free" no título/descrição ou "at no cost").

### 1. Dreams LMS — Free Figma UI Kit for Learning Management Systems

- **Link:** https://www.figma.com/community/file/1542911527930004020/dreams-lms-free-figma-ui-kit-for-learning-management-systems
- **Por que é útil:** UI Kit leve de e-learning com dashboards, telas de gestão
  de cursos, perfis de aluno e módulos de instrutor, todo construído com
  componentes reutilizáveis.
- **O que aproveitar no EduTrack AI:** o padrão de componentes com variantes,
  que ajuda a manter consistência visual entre as telas.

### 2. E learning and Online courses dashboard

- **Link:** https://www.figma.com/community/file/1443251863306978390/e-learning-and-online-courses-dashboard
- **Por que é útil:** reúne vários dashboards de plataformas de cursos online,
  com estética minimalista e moderna (o autor descreve o arquivo como
  "completely free").
- **O que aproveitar no EduTrack AI:** a hierarquia visual e o uso generoso de
  espaço em branco para dashboards densos.

### 3. Task Management & Time Tracking Web Dashboard (Free Figma Template)

- **Link:** https://www.figma.com/community/file/1584063380589294454/task-management-time-tracking-web-dashboard-free-figma-template
- **Por que é útil:** dashboard focado em gestão de tarefas com acompanhamento
  de tempo, com layout voltado à produtividade.
- **O que aproveitar no EduTrack AI:** a visualização de tarefas por status e o
  uso de indicadores de produtividade — base para o acompanhamento acadêmico.

### 4. Plan It — Free Task & Project Management Dashboard UI Kit

- **Link:** https://www.figma.com/community/file/1291115639727516852/plan-it-free-task-project-management-dashboard-ui-kit
- **Por que é útil:** UI Kit de tarefas e projetos que inclui *style guide*,
  componentes, tema claro/escuro e wireframes (versão gratuita).
- **O que aproveitar no EduTrack AI:** o *style guide* e a organização dos
  componentes — referência direta para o design system do EduTrack.

## Maior "sacada"

Ao analisar os templates de outros profissionais, o ponto que mais chamou
atenção foi o quanto a **padronização de componentes** (variantes, auto layout,
design tokens) permite reaproveitar telas inteiras. Dashboards educacionais bem
feitos não "reinventam" a cada página: eles reutilizam os mesmos *cards*,
tabelas e padrões de navegação. Isso muda a forma de planejar o EduTrack AI —
pensar primeiro no **design system e nos componentes** e só depois montar as
telas.
